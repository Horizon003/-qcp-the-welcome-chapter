# QCP — The Welcome Chapter

An animated, mobile-first welcome site for PharmD juniors at Quaid-e-Azam College Pattoki.

## Deploy
Import this repository into Netlify or Vercel. No build command required. Publish directory: `.` (root).

## Haris photo
Place `hyzen.png` (preferred) or `hyzen.jpg` alongside `index.html`. The page tries PNG first, then JPG.
